# CRUD - Sistema de gerenciamento de biblioteca - Projeto de POO
Atividade de conclusão de disciplina

Este projeto é uma aplicação em Java que visa substituir o controle manual de livros e revistas por um sistema estruturado com princípios de Programação Orientada a Objetos (POO).

Foi implementado cadastro de Alunos e Professores com validação de dados, registro de empréstimos com verificação de disponibilidade busca de itens por código, título ou tipo.

Para executar o programa é preciso ter o java instalado, em seguida clone o repositório ou baixe o código-fonte. Navegue até o diretório do projeto e compile os arquivos: javac -d . Main.java ou utilize sua IDE de preferência e execute o programa: java main.Main.

Em conformidade com a Resolução nº 005/2026 - CONSUP, declaro a utilização de ferramentas de Inteligência Artificial (Google Gemini e OpenAI GPT) durante o desenvolvimento deste projeto, conforme detalhado abaixo:

Identificação e correção de erros de sintaxe e lógica

Consultoria sobre bibliotecas padrão do Java e estruturas de dados

Refinamento de métodos para garantir a conformidade com os requisitos solicitados naa atividade avaliativa de programação orientada a objetos (POO).

Todo o código gerado ou sugerido pelas IAs passou por revisão e validação.
